# Proposed changes, 2026-10-14

These changes come from both docs' adoption lists (the CPTC10 report cross-analysis and the finalist repo review), plus the placeholder convention.

The originals are untouched. This folder holds only the new and changed files, at the same paths as in the repo. `changes.diff` has the line-by-line diff.

**To accept:** review, copy these files over the originals at the same paths (or apply `changes.diff`), then delete this folder. You can accept selectively by copying only the files you want.

## Decisions baked in
- **Placeholder markers:** `[[FIELD]]`, `[[CHOOSE: a / b]]`, `[[NOTE: …]]` and `[[TODO: …]]`. The full key is in `templates/README.md`.
  - These replace the first draft's `{{…}}`, which would collide with template-injection payloads (`{{7*7}}`) and with Jinja-based report tools. `<<…>>` was ruled out because of shell heredocs (`<<EOF`).
  - Bash tests always put a space after `[[`, and names are UPPERCASE with no spaces, so the QA search (`[[` followed immediately by uppercase) only matches our markers.
  - Options use `/` instead of `|`, so they don't break Markdown tables.
- **CVSS 3.1 stays.**
- **The QA checklist is its own file,** `checklists/50-report-qa.md`. `report.md` points to it with a `[[NOTE: …]]` line that gets deleted once QA passes.
- **Regionals scope:** the finals-only retest items ("Status vs prior report", remediation-of-prior tables) were left out.
