# Notes

Study notes go here, one file per topic (for example `ad.md`, `web.md`, `ot.md`, `reporting.md`; none written yet).

**The pipeline:** a note becomes useful on competition day only once it has turned into a line on a checklist in `checklists/`. Before the freeze, go through every note and either promote it to a checklist or leave it here as reference.

Remember that this repo is public: write notes about techniques, never about the competition environment.

Suggested note format:

```
## <Technique>
- What it finds / why it works:
- Command(s):
- What the evidence looks like:
- Detection/remediation (for the report):
- ROE risk (could this break or lock something?):
```
